## 2025-05-15 - [Non-semantic buttons in legacy components]
**Learning:** Legacy components using `div` elements with `onclick` handlers but without semantic `<button>` tags or ARIA roles create significant barriers for keyboard and screen reader accessibility. Specifically, `toggleAuthMode` was discovered to rely on DOM child node indices (`childNodes[0]`) when updating UI labels, which makes refactoring to semantic elements delicate.
**Action:** When refactoring `div`-based interactive elements to `<button type="button">`, always use the `btn-reset` class and verify that the exact sequence of child nodes is preserved if the associated JavaScript logic performs manual DOM traversal. Use `display: block; width: 100%` on buttons that replace full-width block-level `div` elements to maintain the original layout.
